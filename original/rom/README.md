# Spectrum 48K ROM

`48k.rom` is the 16 384-byte ROM image that ships in every Sinclair ZX
Spectrum 48K. SHA-1: `5ea7c2b824672e914525d1d5c419d71b84a426a2`.

Source: <https://mdfs.net/Software/Spectrum/ROMImages/48k.rom>.

Provenance: Amstrad plc (which acquired the Sinclair brand and assets
in 1986) granted permission in 1999 for the ROM images to be freely
distributed for non-commercial use, on the condition that copyright
is acknowledged. This copy is bundled solely so that our Z80 emulator
can boot the game; it is not modified.
